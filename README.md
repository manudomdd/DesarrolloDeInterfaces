## 📖 Descripción

Repositorio de la asignatura **Desarrollo de Interfaces** del ciclo formativo de **Desarrollo de Aplicaciones Multiplataforma (DAM)**. 

En este módulo trabajamos con **Java** y **NetBeans** para crear interfaces gráficas de usuario utilizando principalmente **Java Swing**.

---

## 🎯 Objetivos

- Crear interfaces gráficas con Java Swing
- Diseñar aplicaciones de escritorio funcionales
- Implementar eventos y manejo de componentes
- Aplicar buenas prácticas en el diseño de interfaces
- Desarrollar aplicaciones visualmente atractivas y usables

## 🚀 Cómo usar este repositorio

### 1️⃣ Clonar el repositorio

```bash
git clone [url-del-repositorio]
cd desarrollo-interfaces
```

### 2️⃣ Abrir en NetBeans

- Abre NetBeans IDE
- Ve a `File > Open Project`
- Selecciona el proyecto que desees abrir
- Haz clic en `Open Project`

### 3️⃣ Ejecutar el proyecto

- Clic derecho sobre el proyecto
- Selecciona `Run`
- O presiona `F6`

---

## 📚 Contenidos

Los proyectos en este repositorio cubren diferentes aspectos del desarrollo de interfaces:

- ✅ Componentes básicos de Swing (JFrame, JPanel, JButton, JLabel, JTextField)
- ✅ Layouts y organización de componentes
- ✅ Manejo de eventos (ActionListener, MouseListener, etc.)
- ✅ Componentes avanzados (JTable, JList, JComboBox, JMenu)
- ✅ Diálogos y ventanas emergentes
- ✅ Personalización visual de componentes
- ✅ Aplicaciones con múltiples ventanas
